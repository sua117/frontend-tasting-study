### 오늘의 키워드
Component, Props, Array, Map
- Component : 화면에서 찾은 구조를 코드에서도 표현하는 단위 (이름 대문자)
- Props : Component에 값을 전달하는 방법
- Array: 데이터 하나가 Post 하나로
- Map: 배열의 각각을 새로운 결과로

### 느낀점
화면을 어떻게 나눠야할지 잘 모르겠었는데 무슨 역할을 하는지, 비슷한 모습이 반복되는지, 하나의 의미있는 덩어리로 볼 수 있는지를 생각해보니까 조금 개념이 잡히는 것 같다. Component는 화면을 나누고, Props는 값을 전달하고, Array + map는 반복해서 보여준다는 것을 잘 기억해야겠다.
