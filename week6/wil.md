지난 6주 동안 배운 내용 중에 React 코드를 활용해 나만의 게시글을 만들어본 활동이 가장 기억에 남는다. 직접 실습을 해보니까 더 재밌고 기억에 잘 남았다. 그리고 나는 UX와 기능에 관심이 있는 것 같다. 왜냐하면 앱을 만든다면 버튼 누르면 목록이 바뀌는 걸 보는 것과 사용자가 어디서 헤매는지 찾고 고치는 게 재밌을 것 같기 때문이다. 토스 공고를 보니까 서비스의 화면과 동작을 구현하고 동료의 반복 작업을 줄이는 활동들이 궁금해졌다. 구조를 알고 ai에게 요청하는 것이 토큰 낭비와 시간과 비용을 줄인다는 것을 확실히 깨닫고 앞으로 이를 이해한 뒤에 ai를 활용해 개발속도와 완성도를 높이는 연습을 하고싶다.
