### 오늘의 키워드
react, library, ui, jsx
- react : ui를 만들기 위한 도구 (언어 아님)
- library : 다른 프로그램에서 가져다 사용할 수 있도록 만들어놓은 코드의 모음
- ui : javascript + react
- jsx : javascript 안에서 ui를 표현하기 위한 문법
